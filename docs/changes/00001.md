 The sudden drop in rolling average reward was primarily caused by extreme overfitting and training instability. 

  Key Findings
   1. Over-training (High gradient_steps): The previous configuration performed 1,000 gradient updates at the end of every episode (324 steps). This resulted in over 3 updates per step on average, all at once, which caused the network to overfit to the deterministic training data and eventually diverge.
   2. Unstable Gamma (0.9999): A discount factor too close to 1.0 made the Q-value targets extremely sensitive to distant rewards and noise, leading to unstable learning.
   3. Non-Stationary Features: The observation space used absolute values for balance, current_price, and avg_cost. Because the price data had an upward trend, the distribution of these features shifted constantly (non-stationarity), making it difficult for the agent to generalize as it moved through time.
   4. Observation Space Bug: The gym.spaces.Box bounds were set to low=0, which clipped the price_trend feature whenever it was negative, effectively hiding price drops from the agent.

  Applied Fixes
   * Stationary Observations: Refactored CryptoTraderEnv to use relative features (log-returns, ratios, and percentage changes) instead of absolute prices. This ensures the input distribution stays consistent even as prices trend up.
   * Hyperparameter Optimization:
       * Reduced gradient_steps to 1 and set train_freq to 4 steps for more incremental and stable updates.
       * Reduced gamma to 0.99.
       * Increased the exploration_fraction to allow for more robust policy discovery.
   * Reward Consistency: Reduced the invalid_action_penalty from 0.1 to 0.01 to prevent random exploration actions from dominating the trading reward signal.
   * Environment API Compliance: Fixed the observation space bounds to allow negative values and ensured the Gymnasium interface is strictly followed.

  After these changes, the training was re-run for 5,000 episodes. The rolling average reward is now stable and positive, with a final success rate of approximately 92% (vs. the previous drop to 48%).
